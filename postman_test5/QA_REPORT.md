3. **Розділи 19–26 не залежать від стану бази після test4.** Вони самі додають групи до 6, 7 і 11, а всі групи збирають через `GET /groups`. Дисципліни перепризначаються на власних викладачів і зали. У короткій колекції є ще два тести, яким потрібна чиста база:
   - генерація до призначення викладачів і залів дає 409;
   - генерація без жодної групи дає 409.

## Запуск

1. Зупинити сервер, виконати `npm run db:reset` (або видалити `kindergarten.db`), запустити `node index.js`.
2. Імпортувати потрібну колекцію і `kindergarten_qa_local.postman_environment.json` у Postman.
3. В Environment заповнити `adminPassword` **локально, не комітити**, а `baseUrl` встановити відповідно до свого порту (типово `http://localhost:3000`).
4. Запустити Collection Runner: усі запити за порядком, одна ітерація, без перемішування.
5. Для повторного прогону знову очистити базу і перезапустити сервер.

Через CLI:

```bash
npx newman run postman_test5/Kindergarten_API_QA_v5_full_collection.json --env-var baseUrl=http://localhost:3000 --env-var adminPassword=<ADMIN_PASSWORD з .env>
```
